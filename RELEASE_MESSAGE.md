# 🚀 Gallery-DL GUI v1.0.0

¡Llegó la primera versión mayor oficial **Gallery-DL GUI v1.0.0**! Esta entrega consolida una renovación visual integral, selector de tema tri-estado, integración con Aurora Synapse y despacho móvil LAN, nombres de archivo limpios y distribución en un único instalador ejecutable.

## ✨ Novedades destacadas

- 🎨 **Nueva Identidad Visual Canónica**: Icono maestro con canal alfa transparente y empaquetado nativo `.ico` con 10 capas de resolución adaptativa para Windows.
- 🌓 **Selector de Tema Tri-Estado Canónico**: Alterna fluidamente entre Modo Sistema, Modo Claro y Modo Oscuro con renderizado Canvas vectorial puro y persistencia de sesión.
- 🔗 **Integración con Aurora Synapse Protocol**: Esquemas `gallerydl://` y `aurora-synapse://`, registro nativo en Windows (HKCU), endpoint `/synapse` y recepción remota LAN para compartir galerías desde móviles (Lienzo Gallery / Android Share).
- 🏷️ **Nomenclatura Limpia y Título Primero**: Extracción automática del título real al inicio del archivo con numeración cronológica ascendente al final.
- 🔒 **Garantía de Instancia Única (Single-Instance Lock)**: Evita procesos duplicados en memoria con restauración inmediata y enfoque de la ventana activa.
- 📥 **Bandeja del Sistema (System Tray)**: Minimización a segundo plano con menú contextual nativo para descargas desasociadas.
- 📦 **Instalador Único (`.exe`)**: Empaquetado simplificado en un único binario ejecutable firmado digitalmente con Authenticode.
- 🧩 **Conector de Navegador Refinado**: Extensión Manifest V3 actualizada con iconos multi-resolución y sincronización en un solo clic.
