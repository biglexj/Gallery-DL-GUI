# Política de privacidad de Gallery-DL-GUI

**Última actualización: 11 de agosto de 2026**

Gallery-DL-GUI procesa localmente las imágenes, galerías y archivos elegidos por el usuario. No requiere una cuenta, no incorpora publicidad, telemetría ni rastreadores y no envía un historial de descargas a Biglex.

## Operación y Conexiones Directas

Las consultas y descargas se realizan directamente entre el dispositivo, `gallery-dl` y los sitios web que alojan el contenido público. Dichos sitios de origen pueden recibir la dirección IP, cabeceras HTTP y datos habituales de conexión directa según sus propias políticas de privacidad y términos de servicio.

## Almacenamiento Local

La aplicación conserva únicamente preferencias locales, como la ruta de descarga seleccionada, la estructura de carpetas configurada y el historial de descargas con miniaturas locales en el dispositivo del usuario.

## Responsabilidad del Usuario

El usuario es responsable de respetar los derechos de autor, términos de servicio y leyes aplicables al contenido descargado mediante la aplicación.

## Contacto

Para consultas o sugerencias sobre esta política, utiliza el repositorio oficial del proyecto en GitHub (`https://github.com/biglexj/Gallery-DL-GUI`).
